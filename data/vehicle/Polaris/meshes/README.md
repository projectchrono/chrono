# Polaris meshes: trailer hitch

`Polaris_chassis.obj` includes a trailer hitch (object `Hitch`): a cross bar between the rear frame uprights, a 2" receiver, a ball mount, and a ball. The ball is centered at the `Rear Connector Location` of `Polaris_Chassis.json`, where a trailer such as `utv_trailer` attaches. The hitch is generated by the Blender script `add_polaris_hitch.py`; the rest of the chassis mesh is not.

## What the script does

- Builds the hitch geometry in the Polaris chassis reference frame.
- Appends it to the end of `Polaris_chassis.obj`, after a `# Hitch receiver and ball mount` marker. A hitch added by an earlier run is removed first, so the script can be rerun after changing the hitch.
- Adds the materials the hitch uses (`Black`, `Steel`) to `Polaris_chassis.mtl` if they are missing, and updates the material count.

The ball center is set by `P_BALL` at the top of the script. If you change it, change the `Rear Connector Location` in `Polaris_Chassis.json` to match.

## Usage

From this directory (tested with Blender 5.1):

```
blender -b --python add_polaris_hitch.py
```

The script modifies `Polaris_chassis.obj` and `Polaris_chassis.mtl` next to it. To modify copies in another directory, pass that directory after `--`:

```
blender -b --python add_polaris_hitch.py -- <dir>
```

Blender's OBJ exporter does not list the vertex normals in the same order from one run to the next, so a rerun changes the order of the hitch normals in the OBJ file even when the geometry is unchanged.

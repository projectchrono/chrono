# UTV trailer meshes

`utv_trailer_chassis.obj` and `utv_trailer_chassis.mtl` are the visualization mesh of the UTV utility trailer chassis (`UTV_TrailerChassis.json`). They are generated by the Blender script `make_utv_trailer_chassis.py`, so edit the script and rerun it instead of editing the mesh files.

## What the script builds

The trailer chassis mesh, in the chassis reference frame (Z up, X forward, origin at the axle center):

- frame rails, cross members, and deck;
- A-frame tongue and coupler, with the socket centered on the hitch ball at the `Front Connector Location` of `UTV_TrailerChassis.json`;
- raised tongue jack with a caster wheel;
- fenders over the wheels (same track as the Polaris);
- tail lights, light bar, and license plate.

The materials (`Frame_Suspension`, `Chassis`, `Interior`, `Lights`, `Black`, `Steel`) use the names and shading parameters of the Polaris meshes, so the trailer matches the tow vehicle.

Dimensions are set at the top of the script. If you move the coupler (`HITCH`), change the `Front Connector Location` in `UTV_TrailerChassis.json` to match; if you change the track (`TRACK`), change the spindle locations in `UTV_LeafspringAxle.json` as well.

## Usage

From this directory (tested with Blender 5.1):

```
blender -b --python make_utv_trailer_chassis.py
```

The mesh files are written next to the script. To write them elsewhere, pass a directory after `--`:

```
blender -b --python make_utv_trailer_chassis.py -- <out_dir>
```

Blender's OBJ exporter does not list the vertex normals in the same order from one run to the next, so a rerun produces a large diff in the OBJ file even when the geometry is unchanged.
